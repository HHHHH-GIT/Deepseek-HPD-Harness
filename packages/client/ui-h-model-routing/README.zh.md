# @deepseek-ai/dsh-client-ui-h-model-routing

[English](README.md) | 中文

这是持久化 H 路由计划的浏览器展示。插件向 `conversation.input.dock` 提供一个入口，并经 `useProjection` 读取 host 计算出的 `hModelRouting` projection；它不拥有浏览器端调度器、领域 store、刷新链或事件监听器。

复杂任务先显示 `planning`，同时根 Planner 的推理会在主对话中流式展示。Planner 的最终 JSON 仍保存在持久化 Assistant 消息和模型历史中，但浏览器会把该正文显示为默认收起的“规划结果”。DAG 提交后，面板会展开，显示阶段、聚合完成数量，以及列表或任务图。列表模式默认显示简短任务标题、执行状态和选定的 `Light` 或 `Expert` 层；尚未路由或执行前已阻塞的节点也有明确标签。任务图模式使用自动 DAG 布局、SVG 边和只有编号的圆形节点：执行中为蓝色，完成为绿色，失败为红色，待执行和阻塞为灰色。鼠标悬停或键盘聚焦编号节点时会显示模型层，节点的无障碍名称包含任务编号、状态、模型层和依赖。

所选视图和展开状态属于本地展示状态。新 `planId` 会重置为列表模式并默认展开。用户手动收起或选择任务图后，同一计划的后续更新会保持该选择。子 `sessionId` 发布后，对应图节点可以通过键盘或指针操作；激活节点会打开该一次性 subagent 对话。没有会话的待执行节点不可操作。完成、失败和中断计划会持续显示，直到下一项任务清除 projection。面板绝不修改计划、启动节点或恢复中断工作。

## 模型体验

无，因为插件只渲染持久 projection 数据，不添加模型可见内容或系统提示词。

#### KV Cache 影响

无。

## 已知局限与延后工作

- **只读中断状态** - 中断计划可以查看，但面板不提供恢复控件。
- **受限任务图画布** - H 计划最多八个节点；窄屏会让任务图横向滚动，不会缩小或重叠节点。
