# @deepseek-ai/dsh-client-ui-h-model-routing

[English](README.md) | 中文

H model-routing 计划的浏览器展示插件。它向 `conversation.input.dock` 提供一个入口，经 `useProjection` 读取 host 计算出的 `hModelRouting` 投影；不持有浏览器领域 store、不建立刷新链、也不监听事件。复杂任务首先显示已提交的 `planning` 阶段。host 提交顺序子任务后，面板会自动展开，显示当前阶段、任务、完成数量和每个子任务的待处理、进行中或已完成状态。面板会在汇总、完成、规划失败和中断期间持续显示。

折叠状态属于本地展示状态。新的 `planId` 默认展开；用户手动收起后，同一计划后续的进度更新会保持收起。该插件不会修改 H 路由计划、启动工作或恢复中断任务。

## 模型体验

无，因为面板只渲染 host 已经发出的持久会话投影，不发送模型输入，也不添加系统提示词内容。

#### KV Cache 影响

无。

## 已知局限与延后工作

- **只读中断状态**——中断计划保留以供查看，但面板不提供恢复控件；未来的恢复流程必须明确其继续执行权限。
